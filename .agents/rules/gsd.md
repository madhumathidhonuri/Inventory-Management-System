# GSD (Get Shit Done) Standard

## Operating Principles:
1. **Direct Action**: Implement changes directly into the codebase instead of outputting theoretical steps.
2. **Concise Communication**: No fluff, unnecessary preambles, or repetitive summaries. State what was done directly.
3. **Safety & Precision**: Never delete backups or break existing database schemas. Always test edits for syntax and runtime validity before concluding.
4. **Ralph Loop Synergy**: Verify every code modification by running validation checks or node test scripts.
