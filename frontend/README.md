# FuelTracks IMS — Frontend Web & Mobile App

React + Vite + Tailwind CSS frontend application for FuelTracks Technologies Inventory Management System.

## Features
- **Executive Dashboard**: Interactive visual charts (Recharts) and operational metrics.
- **Barcode & IMEI Scanner**: Camera barcode scanner powered by `html5-qrcode` with Continuous Bulk Scanning mode.
- **IMEI Traceability Drawer**: Slide-over drawer providing a full audit trail for any searched IMEI.
- **Field Mobile App View**: Mobile UI tailored for technicians with offline action queue and sync status indicator.
- **Role Switcher**: Quick selector in header bar to test Super Admin, Warehouse Manager, Sales Manager, Installer, and Dealer roles.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.
